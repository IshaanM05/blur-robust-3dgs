# Data

Datasets are git-ignored. Download them here.

- **Mip-NeRF 360** (poses included, no COLMAP needed): `360_v2.zip` from https://jonbarron.info/mipnerf360/
  Extract only `bonsai`, `counter`, `garden` into `data/mipnerf360/` and use the `images_4` folder.
- **Deblur-NeRF**: https://drive.google.com/drive/folders/1_TkpcJnw504ZOWmgVTD7vWqPdzbk9Wx_
  Extract into `data/deblurnerf/`.
